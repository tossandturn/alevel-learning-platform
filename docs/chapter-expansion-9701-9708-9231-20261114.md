## Content authority

Every current chapter has three route-bound `original-foundation-v2` items:
concept retrieval, concrete application and misconception transfer. They are
single-choice, deterministically scored, expose explanations only after
submission and remain `study-only` / `formalProgressEligible: false`.

The target routes contain 138 route chapters and 414 active original items.
There are 114 unique syllabus chapter specifications because the same 9231
component can appear in more than one valid staged route.

Existing machine-indexed 9701, 9708 and 9231 past-paper fragments remain
fail-closed. Their semantic audit still requires human review, so all eight
routes report zero official Chapter Study questions. No OCR-only or quarantine
content was promoted.

## Compatibility

The previous 46 coarse chapter IDs and their 138 v2 questions remain in private
lookup/rebind indexes with byte-stable question semantics. They are not shown
as current chapters. Original-question public projections retain the exact key
set accepted by frozen Mini Program clients; component and syllabus provenance
remain on the existing group containers.

9231 current chapters carry component authority. A P1 chapter cannot start
against P3/P4, and the inventory still returns a legal zero count for every
non-matching route component.
