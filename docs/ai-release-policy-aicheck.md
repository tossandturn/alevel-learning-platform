# AI-reviewed study release

User-approved policy (2026-09-19): one real AI source review may enable student study READY, labelled `AI 审核` (`qualityFlag: aicheck`). No human signature or second model is required. Manual issue review follows release.

The single review receipt binds the exact candidate, reconciled verification, source PDF hashes and reviewed QP/MS page hashes. It records one pass and its reviewer channel. Automated metadata checks are not semantic review. Missing/wrong parts, marks, diagrams, source evidence or topic bindings must be repaired against source material before accepting a question.

Existing two-pass study releases remain supported without rewriting historical reviews. `formalProgressEligible` remains false for AI-reviewed study. Acceptance of question data does not automatically mean every chapter has enough unique questions to generate its default set.
