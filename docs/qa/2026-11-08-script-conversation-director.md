# 剧本短句对话与 DM 引导验收

范围：现有剧本房间的角色回复与操作引导。既有故事、线索、机关、个人决定、支付、登录、AI Coach 和人物图片均未改写。

## 本地检查

- 新增默认短聊与详细解释两个有界回复预算；只在标点和段落边界分气泡，不截断句子或证据。
- “这句话我记下了”等套话、空泛接话、暂停后追问和过长回复在入库前校验，最多进行一次重答，重复无效内容不保存。
- 短回应时给具体话题；明确要求安静时不继续追问。没有增加无人值守的自动生成循环。
- DM 开场说明放在角色入场之后，现版自动滚到底部时可见。关键步骤只提示下一步；个人提示仅自己可见，读取/重连不重复发提示。
- UI 指引与对应操作提问不进入角色记忆；叙事旁白、真正的私聊约定、固定经历及已经完成的阶段仍保留。
- 新增 conversation / conversation API / director 测试通过。现有房间、角色、跨幕记忆、场景、素材、校园、威尼斯及冰岛相关回归保持通过。未运行整个题库项目全量构建。
- 冻结客户端 `1.0.92 / 83b8d9f` 的 7 个新增状态视图通过；使用现有 `parts` 气泡，无客户端代码更改。

## 附件与参考边界

附件以共享只读方式读取，保留原文件；四段文字与一张账户页截图均已检查，无批注或修订标记。本机没有打包的 LibreOffice，不执行用户桌面 Office 渲染，也不声称审核了 DOCX 排版。

文档新增的重复登录/昵称、物理图解、人物重绘，以及更广的双人剧本质量复审，已向用户确认是否一并实施；这部分不在本次已完成范围。公开同名参考未确认是所指的百变版本，不复制或改编其台词、故事。
